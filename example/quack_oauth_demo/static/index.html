This is a live demo of quack-oauth: the data on display is hosted by an in-process DuckDB on this machine, served over the quack wire protocol, and gated by your Google identity.

The browser runs DuckDB-Wasm with the quack and quack_oauth extensions. Authentication uses the Google OAuth 2.0 Web Server flow; the resulting opaque access token is validated on the server via Google's oauth2.googleapis.com/tokeninfo endpoint.
