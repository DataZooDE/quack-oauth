This is a live demo of quack-oauth: the data on display is hosted by an in-process DuckDB on this machine, served over the quack wire protocol, and gated by your GitHub identity.

The browser runs DuckDB-Wasm with the quack and quack_oauth extensions. Authentication uses the GitHub OAuth Web Flow; the resulting user-to-server token is validated on the server via GitHub's /applications/…/token endpoint.
